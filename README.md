# Candy Bar Adventure – Android
Wraps the original SWF (Flash 8 / AS2, 550x400, 18fps) in a WebView running the Ruffle Flash emulator (bundled offline).
Build: open this folder in Android Studio -> Run, or `gradle assembleDebug` (Android Studio creates the Gradle wrapper).
Ruffle is MIT/Apache-2.0 (see app/src/main/assets/ruffle/LICENSE_*).
